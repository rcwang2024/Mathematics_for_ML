# Mathematics for Machine Learning

![Jupyter](https://img.shields.io/badge/Jupyter-notebooks-F37626?logo=jupyter&logoColor=white)
![Python](https://img.shields.io/badge/Python-NumPy%20%7C%20SciPy%20%7C%20scikit--learn-3776AB?logo=python&logoColor=white)

A structured, code-first path through the mathematics behind machine learning — from algebra to measure theory and
statistical learning theory. Each notebook combines concise theory with NumPy/SciPy implementations and visualisations,
and connects the concepts to where they appear in ML practice.

## How to use

```bash
git clone https://github.com/rcwang2024/Mathematics_for_ML.git
cd Mathematics_for_ML
pip install numpy scipy pandas scikit-learn matplotlib seaborn sympy networkx jupyter
jupyter lab
```

Work through the levels in order, or jump to a topic — each notebook is self-contained.
